# My nvim config

Clone this repository into `~/.config`. After cloning you should see a new
directory called `nvim`.

Currently using Packer. Packer is not maintained anymore. Will need to
replace. Consider using lazy.

Install packer first.

```shell
git clone --depth 1 https://github.com/wbthomason/packer.nvim\
 ~/.local/share/nvim/site/pack/packer/start/packer.nvim
```

Then launch neovim and run `:PackerSync`.
